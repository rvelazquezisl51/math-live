# Math Live V5.8.2 — Identidad visual aprobada

Versión completa basada en V5.8.1.

## Cambios V5.8.2
- Integra la imagen visual aprobada de Math Live como escenario principal del acceso del estudiante.
- El panel HTML funcional cubre la zona central de la ilustración: no aparece el antiguo rectángulo verde ni una segunda interfaz utilizable detrás.
- Mantiene 18 avatares gráficos.
- Mantiene accesos separados: estudiante (`index.html`), maestro (`teacher.html`) y TV (`present.html`).
- Mantiene autenticación del maestro, acceso anónimo del estudiante y reglas de seguridad de V5.7.
- Mantiene cronómetro, cierre de nuevas entradas cuando inicia la partida y registro de preguntas sin responder.
- Si un estudiante deja la partida, no existe botón de abandonar y no afecta a los demás; su resultado conserva el total de desafíos (ej. 5/15) y los restantes quedan como sin responder.
- Cache busting actualizado a V5.8.2 (`?v=582`).
